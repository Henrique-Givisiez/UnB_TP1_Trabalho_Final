Detailed Description

Classe responsável pelo armazenamento em memória dos dados do sistema.

Esta classe centraliza os containers usados pelos serviços reais. Todos os serviços devem compartilhar a mesma instância desta classe para garantir consistência entre Pessoas, Projetos, Planos de Sprint e Histórias.
