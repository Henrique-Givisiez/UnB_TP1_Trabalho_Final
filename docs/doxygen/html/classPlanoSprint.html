Detailed Description

Entidade que representa um Plano de Sprint no sistema Scrum.

Agrega os domínios Codigo (PK), Texto (objetivo) e Tempo (capacidade). Toda validação é delegada aos respectivos domínios; nenhuma regra de negócio vive nesta classe.
