Detailed Description

Entidade que representa uma História de Usuário no sistema Scrum.

Agrega os domínios Codigo (PK), Texto (titulo, acao, valor), Papel, Tempo (estimativa), Prioridade e Estado. Toda validação é delegada aos respectivos domínios; nenhuma regra de negócio vive nesta classe.

Uma história pertence exclusivamente a um Projeto ou a um Plano de Sprint — nunca aos dois simultaneamente (restrição {OU} do diagrama). Essa restrição é controlada pela camada de serviço.
