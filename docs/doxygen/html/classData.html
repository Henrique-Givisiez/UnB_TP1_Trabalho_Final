Detailed Description

Domínio que representa uma data no formato DIA/MES/ANO.

Formato válido: DIA/MES/ANO

  • DIA: 1 a 31
  • MES: 01, 02, ..., 12
  • ANO: 2000 a 2999 Data deve ser válida considerando anos bissextos.
